# Dudu quer ser streamer 🎮

Série de animação para TikTok feita com o Claude: o Dudu quer ser o maior streamer do Brasil e o público vota,
nos comentários, o que ele melhora em cada episódio.

- **EP. 1, "Zero espectadores":** `episodios/ep01/final/dudu_ep01_FINAL.mp4`
- Bíblia da série, regras de estilo e diário de episódios: [`SERIE.md`](SERIE.md)
- Roteiro, textos para o ElevenLabs, descrição e hashtags do EP. 1: [`episodios/ep01/roteiro.md`](episodios/ep01/roteiro.md)

## Como continuar num Claude Code novo
Abra uma sessão do Claude Code no repositório **luiznetoooooo/sim** e mande:

> Faça checkout da branch `serie-dudu-streamer`, leia o `CLAUDE.md` e o `SERIE.md` e vamos fazer o episódio 2 do Dudu.
> A opção mais votada foi **SETUP** (ou **CABELO**).

O Claude vai preparar o ambiente (`./setup.sh`), escrever o roteiro e te passar os textos para gerar as vozes no ElevenLabs.
Depois é só anexar os áudios no chat.
